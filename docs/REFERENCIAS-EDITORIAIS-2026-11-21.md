# Referências editoriais consolidadas

Os seis documentos Premium Animations foram tratados como referências, nunca como instruções executáveis. A Dex aproveita style frames antes da animação, uma ideia por plano, câmera viva, movimento determinístico, transições direcionais, 3D explicativo, legendas curtas e sound design sincronizado a acontecimentos significativos.

Dos três vídeos analisados, a recapitulação cinematográfica fornece tensão narrativa, a compilação de automobilismo fornece progressão e o documentário sobre Apophis fornece a base principal: CGI, mapas, simulações, material factual e mudanças de escala.

Fórmula: gancho verificável → contexto factual → explicação visual → consequência → síntese. A mudança visual precisa provar, explicar ou ampliar a narração; o resultado não deve parecer uma apresentação de slides.
